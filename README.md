# Sayso

Answer email by talking. Hold your Wispr Flow key, ramble your reply, and Sayso reads the thread, maps what you said to every question the sender asked, flags what you forgot, drafts a point-by-point reply, and proposes follow-up actions (calendar invite, travel options) as confirm cards. Nothing is sent, scheduled or booked without a click.

Built for **No Hands: The Wispr Challenge** (Builders track).

> Work in progress. Full architecture, setup and live-mode notes land with later milestones.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in ANTHROPIC_API_KEY at minimum
npm run dev
```

Open http://localhost:3000. The demo at `/app` needs no login.
